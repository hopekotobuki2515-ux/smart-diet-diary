# SMART Diet ダイアリー

四群点数法をベースに、食事写真と簡単な群選択で毎日の食べ方を振り返るスマホ向けWebアプリです。

## 試作版の方針
- 朝食・昼食・夕食・間食を写真で記録
- 1〜4群をタップで選択
- 3群は緑黄色野菜・淡色野菜・きのこ/海藻・いも・果物を簡易確認
- 4群は0.5点刻みで入力し、1日目安との差を表示
- 1点 = 80kcal
- 女性15点/日、男性21点/日を初期目安として表示
- 写真はブラウザ内で長辺1280px以下・JPEG品質約76%へ圧縮

## 現在の保存方式
試作版では localStorage のみを使用しています。Firebase Authentication / Firestore / Storage はUI確認後に接続予定です。

## 予定
- Firebaseログインとユーザー別保存
- 圧縮画像のFirebase Storage保存
- 1日・1週間の振り返り
- デフォルトコメント判定
- 出典・参考情報ページ
- 300人規模を想定した保存量管理

※食品成分値や栄養基準、四群分類の出典は公開前に最新版・利用条件を最終確認します。
